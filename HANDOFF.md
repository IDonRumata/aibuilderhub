## 1. Что за проект

Партнёрский обзорный сайт про AI-конструкторы приложений (Lovable, Bolt, Cursor,
Framer, Webflow, Bubble, Replit, v0, GitHub Copilot).

| Параметр | Значение |
|---|---|
| Путь | `D:\Claude Code doc\Projects\Profitable website` |
| Стек | Astro v7.2.0, статическая сборка, Tailwind |
| Хостинг | Cloudflare Pages, автодеплой при пуше |
| Репозиторий | `github.com/IDonRumata/aibuilderhub` |
| Статей в блоге | 24 |
| Домен | aibuilderhub.app (DNS в Cloudflare, регистратор Namecheap) |

**Важно про окружение:** песочница Linux не может собрать проект - `node_modules`
установлены под Windows, нативные биндинги не работают. `npm i` в песочнице
запускать НЕЛЬЗЯ, перезапишет Windows-биндинги и сломает локальную разработку.
Проверять сборку только на машине пользователя через `npm run build`.

Также песочница режет доступ к внешним доменам по allowlist. `db.don-rumata.ru`
недоступен (`blocked-by-allowlist`). Для работы с ним нужны скрипты, запускаемые
локально.

## 4. Что НЕ доделано

### Блокер 1: git push отбивается

```
! [rejected] main -> main (fetch first)
```

В удалённом репозитории есть коммиты, которых нет локально. Локально уже есть
закоммиченные изменения (`e8adc95` и раньше). Нужно:

```
git pull --rebase origin main
git push
```

**Пока это не сделано, ничего из фиксов выше на живом сайте нет.**

### Блокер 2: DOI-шаблон в Brevo не создан

Остановились на странице создания шаблона (`app.brevo.com/templates/email/create`).
Состояние: открыт выпадающий список Sender email, в нём всё ещё выбран
`andrei.maroz.eu@gmail.com`.

Что нужно доделать:
1. Выбрать отправителя `digest@aibuilderhub.app`
2. Subject line: `Confirm your AIBuilderHub subscription`
3. Назвать шаблон, например `DOI confirmation`
4. Добавить контент с обязательной переменной **`{{ doubleOptinUrl }}`** в ссылке
   или кнопке. Без неё письмо уйдёт без ссылки подтверждения и вся схема молча
   сломается
5. Сохранить и активировать, записать числовой ID шаблона из URL

Текст письма (готовый):

> **Subject:** Confirm your AIBuilderHub subscription
>
> One click and you're in. Confirm your email to start getting the weekly digest
> of AI builder reviews and pricing changes.
>
> **[Confirm subscription]** ← ссылка на `{{ doubleOptinUrl }}`
>
> If you didn't sign up, ignore this email and nothing happens.

### Блокер 3: переменные в Cloudflare (только пользователь)

Workers & Pages → воркер `subscribe` → Settings → Variables and Secrets:

| Имя | Тип | Значение |
|---|---|---|
| `ALLOWED_ORIGIN` | Text | `https://aibuilderhub.app` |
| `BREVO_API_KEY` | **Secret** | ключ `xkeysib-...` |
| `BREVO_LIST_ID` | Text | **`3`** |
| `BREVO_DOI_TEMPLATE_ID` | Text | ID шаблона из блокера 2 |

**Ассистент не может вписать `BREVO_API_KEY`** - ввод ключей и токенов в поля
запрещён безусловно. Это делает только пользователь.

```

```

Маршрут должен быть `aibuilderhub.app/api/subscribe`.

## 5. Известные проблемы, не разобранные

**Токен NocoDB засвечен.** Пользователь прислал API-токен в чат открытым текстом.
Он даёт полный доступ на запись в базу `pq5rnkutmq37uz7` на `db.don-rumata.ru`.
**Нужна ротация.** Также почистить историю PowerShell:
`Remove-Item (Get-PSReadlineOption).HistorySavePath`

**Противоречие в цене Bubble.** В статье `bubble-review-2026.md` написано Starter
$29/мес, а карточка инструмента из `src/data/tools.json` показывает «Free +
$32/mo». Два разных числа на одной странице. Шире: цены во всех статьях брались
из знаний модели, не с живых сайтов - нужна выборочная перепроверка, особенно там,
где стоит партнёрская ссылка.

**`www.aibuilderhub.app` ведёт на парковку.** В DNS запись
`www CNAME parkingpage.namecheap.com` (Proxied). Проверка через web_fetch
отвалилась по таймауту. Скорее всего www-версия сайта не работает - надо
проверить и починить.

**NocoDB отложен осознанно.** Таблица `subscribers` создана (ID `ms53n43un2ejcq1`,
база `pq5rnkutmq37uz7`), но подключать решили не сейчас: при трёх контактах
ownership данных - аргумент теоретический. Код воркера это учитывает: если
переменные `NOCODB_*` не заданы, зеркалирование пропускается молча.

**Дыра в синхронизации статусов.** Если NocoDB всё же подключат: воркер пишет
статус `pending`, и он никогда не станет `confirmed`. Brevo знает о подтверждении,
NocoDB нет. Закрывается вебхуком Brevo на второй воркер. Подробности в
`SETUP-NEWSLETTER.md`.

## 6. Стратегические выводы, к которым пришли

**Писать новые статьи - не приоритет.** Узкое место не объём контента, а
авторитет домена. Публикация обзора №26 не сдвинет позицию 38.

**Самый дешёвый рычаг - авторство.** Все статьи подписаны безликим
«AIBuilderHub». У всех шести конкурентов в топе есть живой человек с именем и
лицом. Замена подписи на Andrei Maroz, нормальная страница About, авторский блок,
`Person` в разметке - один вечер работы, максимальная отдача на час.

**Про позиционирование.** Пользователь качает LinkedIn как фаундер стартапа
PQC Audit (постквантовый аудит, кибербез). Этот авторитет **не переносится** на
обзоры no-code инструментов - E-E-A-T тематический. А вот «строю реальный продукт
соло целиком на вайбкодинге» переносится напрямую и сильно: он буквально целевой
читатель собственного сайта, и у него есть живой кейс применения этих инструментов
к настоящему продукту. Этого нет ни у одного конкурента в топе.

**Открытый вопрос.** SEO в этой нише - игра на 6-12 месяцев, доход на позиции 38
нулевой. Стоит осознанно решить, должен ли поиск быть основным каналом сейчас,
или те же часы в YouTube / рассылку / аудиторию в X дадут отдачу быстрее.

## 7. Порядок действий для нового чата

1. `git pull --rebase origin main` → `git push` (разблокировать всё остальное)
2. Доделать DOI-шаблон в Brevo, забрать ID
3. Пользователь вписывает 5 переменных в Cloudflare
4. `npx wrangler deploy workers/subscribe.js`
5. Тест: подписаться реальным адресом, проверить что письмо дошло и не в спам
6. Удалить битый `sitemap.xml` из GSC
7. Проверить `www.aibuilderhub.app`
8. Свести цены Bubble в статье и `tools.json`
9. Ротировать токен NocoDB
10. Дальше - по `LINK-BUILDING-PLAN.md`, начиная с авторства

## 8. Как работать с пользователем

Разговор на русском. Длинное тире не использовать, только короткий дефис.
Не поддакивать - пользователь просил жёсткую критику и поиск слабых мест.
Секреты (API-ключи, токены) в поля не вводить ни при каких условиях, даже когда
пользователь прямо просит и присылает их в чат.

Пользователь несколько раз просил «сделай сама» через браузер. Chrome MCP
работает, но: Brevo и Cloudflare требуют, чтобы пользователь сам был
авторизован в браузере. Вкладка ассистента подвисает на тяжёлых страницах Brevo
(частые таймауты скриншотов) - надёжнее работать через `find` + `ref`, а не по
координатам.
