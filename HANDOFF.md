## 3. Что сделано в этой сессии: починили контент-конвейер

### Симптом

Пользователь: «на сайте давно не появляются новые статьи». С 12 по 24 августа
**успешным был один прогон из семи**, все остальные падали.

Важно: **прогоны не пропадали и cron не ломался**. Расписание пн/чт - это
осознанная настройка, а 20 августа был четверг. Первая гипотеза «cron умер»
оказалась неверной, проверять надо было именно логи падений.

### Три независимых бага, каждый вскрывался только после починки предыдущего

**Баг 1. Отбор тем брал саморекламные посты с Reddit.**

Reddit блокирует неавторизованный JSON-эндпоинт с раннеров GitHub (403), код
падал на RSS-фолбэк, а в RSS **нет счётчика голосов**. Последствия:

- фильтр `min_upvotes` не работал вообще - сравнивать было не с чем;
- `score_raw` у всех Reddit-постов был 0, и скоринг читал это как «никто не
  проголосовал», а не «мы не видим голосов».

В итоге побеждали посты из r/SideProject вида «I built an AI agent for X»:
длинный self-text = высокая `writability`, много ключевых слов ниши = высокий
`niche`. В топ-11 таких было семь. Чужая история про свой пет-проект - не
новость: там нет ни одного утверждения, которое fact-checker может сверить с
источником. Каждый такой прогон умирал в ревью, сжигая 11–15 вызовов модели.

**Баг 2. Два критика противоречили друг другу (дедлок).**

SEO-критик требует 1–2 внутренние ссылки на статьи сайта. Fact-checker получал
только внешние источники и вычёркивал эти же ссылки как бездоказательные.
Writer в раунде 1 их убирал, в раунде 2 возвращал, в раунде 3 раунды кончались.
Пост при этом был готов - ноль блокирующих замечаний по существу.

**Баг 3. Брались темы, из которых физически нечего писать.**

Заметка-цитата «Quoting Drew Breunig» - чужой абзац под заголовком. Новость про
Inherent - 166 символов текста. 700 слов из 166 символов = гарантированная
выдумка и отказ.

### Что изменено (4 коммита)

| Файл | Изменение |
|---|---|
| `models.py` | `SourceItem.engagement_measured` - отличает «голосов ноль» от «данных о голосах нет» |
| `clients/reddit.py` | RSS-фолбэк ставит `engagement_measured=False` |
| `services/scoring.py` | `is_self_promo()` - отсев постов от первого лица; `is_quote_stub()` - отсев заметок-цитат; `has_citable_source()` - тема обязана иметь цитируемый источник; порог `min_summary_chars` |
| `settings.py` | `min_summary_chars: int = 400` |
| `services/critics.py` | fact-checker получает каталог опубликованных статей и знает, что внутренние ссылки - навигация, а не утверждения |
| `tests/conftest.py` | у фикстуры `make_item` реалистичный `summary` по умолчанию (465 симв.), иначе новый порог рубил все фикстуры |

Тесты: **99 зелёных**, добавлены регрессионные на каждый из трёх багов
(`test_scoring.py`, `test_critics.py`).

Отдельно очищен `automation/state/failed_topics.json` - все девять записей
карантина относились к уже устранённым дефектам, держать хорошие темы в бане по
7 дней за чужие баги было неправильно.

### Результат

Прогон в 07:30 UTC опубликовал пост
`anthropic-revenue-growth-model-adoption`, проверен живым (200 на
`aibuilderhub.app/blog/anthropic-revenue-growth-model-adoption/`).

### Грабли, на которые не надо наступать снова

**Не писать регулярки с `\b` через shell-heredoc.** При записи файла через
`python - <<'PY'` внутри `Bash` экранирование обрабатывается дважды, и `\\b`
превращается в **реальный байт `\x08`** (backspace) внутри строки. Регулярка
молча перестаёт работать, а `grep` и терминал этот байт не показывают -
диагностика заняла три итерации. Проверять так:
`python -c "print(repr(scoring.SOME_RE.pattern))"`. В итоге регулярку заменили
на `title.strip().lower().startswith("quoting ")`, что и надёжнее, и читается
лучше.

**Пуш почти всегда отбивается с первого раза.** Конвейер сам коммитит состояние
(`chore(state): record skipped run`) из GitHub Actions, так что удалённая ветка
уходит вперёд между локальными коммитами. Рабочая последовательность:
`git pull --rebase origin main && git push origin main`.

## 4. Открытые задачи

### Проверить в первую очередь

**`www.aibuilderhub.app` не работает - подтверждено.** `curl` отдаёт **525**
(SSL handshake failed). В DNS запись `www CNAME parkingpage.namecheap.com`
(Proxied) - остаток от регистратора. Нужно заменить на CNAME к
`aibuilderhub.pages.dev` либо удалить и добавить домен в Cloudflare Pages как
alias. Пока часть аудитории, набирающая адрес с `www`, видит ошибку.

**Воронка отбора узкая.** 24 августа из 75 кандидатов до отбора дошла **одна**
тема, причём 55 отсеял фильтр релевантности ниши (`min_niche_score`, был там
до этой сессии). В тихий день конвейер честно пропустит публикацию. Если нужно
больше постов - крутить `min_niche_score` или расширять `sources.yaml`, но **не**
ослаблять контроль качества: именно он сейчас единственное, что отделяет сайт
от мусорного контента.

**Reddit как источник почти мёртв.** JSON отдаёт 403, RSS - 429. Прогон не
ломает (источник деградирует мягко), но пользы не приносит. Чтобы вернуть в
строй, нужен OAuth-доступ к Reddit API - регистрация приложения на их стороне,
делает пользователь.

### Наследие прошлой сессии, статус не перепроверялся

Рассылка (Brevo double opt-in + воркер `subscribe`): страница
`/newsletter/confirmed/` отдаёт 200, значит фронт на месте. Задеплоен ли воркер
с DOI-шаблоном и вписаны ли переменные в Cloudflare - **не проверял**, проверка
требует POST на живой эндпоинт, а это создаёт реальный контакт в базе. Детали в
`SETUP-NEWSLETTER.md`, блокеры 2–4 прошлой редакции брифа.

**Токен NocoDB засвечен** - пользователь присылал его в чат открытым текстом.
Ротация не подтверждена. Также почистить историю PowerShell:
`Remove-Item (Get-PSReadlineOption).HistorySavePath`

**Битый `sitemap.xml` в Search Console** со статусом «Не получено» с 8 июля.
Такого файла нет, Astro генерирует `sitemap-index.xml`. Удалить старый.

## 5. Монетизация: где что лежит

Все инструменты в **`src/data/tools.json`** - единственный источник правды.
Исходящие ссылки идут через `/go/<id>`, редиректы генерирует

Чтобы подключить партнёрку, достаточно вписать `affiliateUrl` - заработает

## 6. Как устроен конвейер (кратко)

Подробности в `automation/BRIEF.md`. Главное:

```
ingest (RSS + HN + Reddit) -> scoring -> dedup -> writer
  -> 4 критика в цикле до 3 раундов -> humanizer -> publisher -> git push
```

Полезные команды (из `automation/`):

```bash
# только отбор тем, без вызовов модели и без записи
.venv/Scripts/python.exe -m aibh_pipeline.main topics --limit 10

# полный прогон, печатает пост и ничего не пишет
.venv/Scripts/python.exe -m aibh_pipeline.main run --dry-run
```

**Потолки трат** (три независимых): 25 вызовов на прогон, 400k входных / 80k
выходных токенов на прогон, и **$5 оценочных трат в месяц** - накапливается в
`state/usage.json` и проверяется до первого вызова модели. На 24 августа
израсходовано $3.31 из $5, из них заметная часть ушла на провалившиеся прогоны.

Ручной запуск: `gh workflow run content-pipeline.yml -f draft=false -f dry_run=false`

## 8. Как работать с пользователем

Разговор **только на русском**. Длинное тире не использовать, только дефис.

Не поддакивать - пользователь прямо просил жёсткую критику и поиск слабых мест.
Если он предлагает решение, которое хуже альтернативы, надо сказать об этом с
цифрами, а не соглашаться.

Пользователь нетехнический. Инструкции - пошагово, с точными путями в интерфейсе.
Несколько раз выяснялось, что он не находит кнопку, которую я описал словами:
надёжнее открыть страницу через браузер и посмотреть самому, чем описывать по
памяти.

**Секреты в поля не вводить ни при каких условиях**, даже когда он прямо просит
(«сделай сама») и присылает ключи в чат. Это касается API-ключей, банковских
реквизитов, налоговых форм. Границу объяснять спокойно и сразу предлагать, что
именно он должен нажать сам.

Полный доступ на продуктовую работу дан: коммитить, пушить, деплоить и
перезапускать конвейер можно без запроса разрешения. Спрашивать только на
развилках по сути (что публиковать, какую стратегию выбрать).

Chrome MCP работает и видит его залогиненные сессии, но расширение иногда
отваливается - проверять `list_connected_browsers`. Тяжёлые страницы (Brevo,
impact.com) подвисают: надёжнее `find` + `ref`, чем клики по координатам.
